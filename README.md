# 刘奶蛙的个人主页

一个复古未来风的自我介绍网页，黄色为主色调，包含个人照片、基本信息，以及"我的写真"图片展示区。

## 文件结构

```
.
├── index.html          # 网页主文件
├── face.png             # 主界面大图
├── info.txt             # 基本信息原始文本（网页内容已手动填入 index.html，此文件仅作留存）
└── 我的写真/
    ├── 我和朋友拥抱.png
    ├── 我惊讶.png
    └── 我捧腹大笑.png
```

## 本地预览

直接双击 `index.html` 用浏览器打开即可。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（Public）。
2. 把上面文件结构里的所有文件和文件夹，原封不动地放进仓库根目录。
3. 提交并推送到 `main` 分支。
4. 在仓库的 Settings → Pages 中，Source 选择 `main` 分支、根目录 `/`，保存。
5. 等待 1-2 分钟，GitHub 会给出一个形如
   `https://你的用户名.github.io/仓库名/` 的访问地址。

## 注意事项

- 图片文件夹和文件名包含中文字符（"我的写真"、"我惊讶.png" 等），GitHub 和浏览器都能正常支持，无需改名；如果之后遇到图片加载不出来的情况，可以尝试把文件夹和图片名改成英文（如 `photos/hug.png`），并同步修改 `index.html` 里对应的 `src` 路径。
- `index.html` 中的图片路径都是相对路径，只要文件夹结构和上面一致，部署到任何静态托管平台（GitHub Pages、Vercel、Netlify 等）都可以直接使用。
